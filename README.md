# Endfield UID Mask / 身份显示伪装

适用于《明日方舟：终末地》的本地画面隐私保护模组。在录制视频或截图分享时，自动将画面中渲染的 UID、玩家昵称及 # 编号替换为自定义别名，防止个人账号信息泄露。

---

## 功能特性

- **底层文本渲染替换**：在 TextMeshPro 文本处理汇合层进行即时置换，覆盖游戏主界面 HUD、ESC 菜单、个人名片及结算水印等展示区域。
- **纯本地视觉伪装**：仅在渲染呈现阶段替换文本，不影响游戏的原始文本、网络通信与名片复制功能。
- **即时生效与热重载**：在模组菜单中修改别名或切换开关后，当前界面中的文字立即重绘生效，无需重启游戏。

---

## 使用与配置

安装模组后进入游戏，按 `ESC` →「模组菜单」→「身份显示伪装」→「模组配置」：

- **伪装 UID**：开启后将画面中的真实 UID 替换为自定义数字（默认 `1000000000`，支持 1–20 位数字）。
- **伪装玩家昵称**：开启后将角色昵称标签替换为自定义文本（默认 `管理员`，支持中文）。
- **伪装昵称 # 编号**：开启后仅在玩家名片及完整昵称组合中替换 `#` 后的数字编号（默认 `0000`）。

> **说明**：此模组仅改变本地显示画面。若使用游戏内的复制 UID 按钮，复制出的内容仍为原始真实信息。

---

## 构建与安装

### 构建

```powershell
.\tools\build.ps1
.\tools\package.ps1
```

构建产物位于 `build/package/Release/uid-mask`。

### 安装

退出游戏后，通过 ModLoader 的安装工具进行部署：

```powershell
..\Endfield-ModLoader\tools\install-mod.ps1 -ModPackage .\build\package\Release\uid-mask
```

个人自定义配置保存在 `%LOCALAPPDATA%\EndfieldModLoader\mods\uid-mask\config.ini`。
