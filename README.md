# UID 遮挡 (UID Mask)

为《明日方舟：终末地》提供本地画面隐私保护，在录屏或截图时将画面中渲染的 UID、玩家昵称及 # 编号替换为自定义文本，防止个人信息泄露。

## 功能特性

- **全局视觉替换**：覆盖游戏主界面 HUD、ESC 菜单、个人名片及结算水印等展示区域。
- **纯本地视觉伪装**：仅在客户端渲染阶段替换文本，不影响实际账号通信与原生复制功能。
- **即时生效与热重载**：在模组菜单中修改后即时刷新画面，无需重启游戏。

## 配置项说明

在游戏内按 `ESC` →「模组菜单」→「UID 遮挡」即可配置：

- **伪装 UID**：开启后将画面中的真实 UID 替换为自定义数字（如 `1000000000`）。
- **伪装玩家昵称**：开启后将角色昵称标签替换为自定义文本（如 `管理员`）。
- **伪装昵称 # 编号**：开启后在名片及完整昵称中替换 `#` 后的数字编号（如 `0000`）。
